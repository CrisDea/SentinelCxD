# Security policy

## Supported versions

Only the latest published release is supported with security updates.

## Report a vulnerability

Use GitHub private vulnerability reporting for this repository:

https://github.com/CrisDea/SentinelCxD/security/advisories/new

Do not open a public issue or include credentials, customer identifiers,
production logs, access tokens, or exploit details in public discussions.

Include the affected release, deployment path, impact, reproduction steps, and
the smallest safe evidence needed to validate the report. Reports are
acknowledged as soon as practical and are coordinated privately until a fix or
mitigation is available.
